# FiberOps

FiberOps هو تطبيق ويب عربي RTL لإدارة عمليات مشاريع الألياف الضوئية. يدير التطبيق ملفات العمالة والإقامات والمؤهلات والوثائق والتكليفات، إضافة إلى الأقسام والمشاريع وبكرات الكابلات والمعدات والتصاريح والمسارات. تعتمد جميع إجراءات الإضافة والتعديل والحذف والتجديد والتعيين على قاعدة بيانات MySQL وسجل تدقيق تشغيلي.

## التشغيل بـ Docker Compose

يتضمن المشروع إعداداً كاملاً لتشغيل التطبيق وقاعدة MySQL على أي خادم Docker حديث. انسخ قالب البيئة، حدّث أسرار قاعدة البيانات و`JWT_SECRET`، ثم شغّل الحاويات:

```bash
cp docker.env.template .env
# عدّل .env بالقيم الآمنة والخاصة ببيئتك
docker compose up --build -d
```

يفتح التطبيق افتراضياً على `http://localhost:3000`. يبدأ التطبيق بعد التحقق من جاهزية MySQL ويطبق ترحيلات Drizzle تلقائياً. لمراقبة السجلات استخدم `docker compose logs -f app`، ولإيقاف التطبيق استخدم `docker compose down`. تبقى بيانات قاعدة البيانات في وحدة Docker المسماة `fiberops_mysql_data`، ولا تحذفها إلا إذا أردت مسح البيانات نهائياً.

## إعداد البيئة والمصادقة

| المتغير | الغرض |
| --- | --- |
| `MYSQL_PASSWORD` و`MYSQL_ROOT_PASSWORD` | كلمات مرور قاعدة البيانات داخل Docker Compose. |
| `JWT_SECRET` | مفتاح توقيع جلسات التطبيق؛ يجب أن يكون طويلاً وعشوائياً. |
| `LOCAL_ADMIN_USERNAME` | اسم حساب المسؤول الأولي عند تشغيل التطبيق في بيئة جديدة. |
| `LOCAL_ADMIN_PASSWORD` | كلمة مرور المسؤول الأولي. احفظها كسِرّ بيئة ولا تضعها في الكود أو GitHub. |

> لا ترفع ملف `.env` إلى GitHub ولا تشاركه. يحتوي هذا المستودع على `docker.env.template` فقط كنموذج آمن.

## أوامر التطوير والتحقق

```bash
pnpm install
pnpm check
pnpm test
pnpm build
```
